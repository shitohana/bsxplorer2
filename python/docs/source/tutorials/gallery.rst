Plot gallery
============

This gallery explains what each main BSXplorer2 plot is intended to show.

Metagene line
-------------

Use this plot for the first high-level view of profile shape across the chosen
gene or region set.

Metagene heatmap
----------------

Use this plot to inspect row-wise structure, profile heterogeneity, and ranked
patterns that are hidden in the mean curve.

Metagene box / violin
---------------------

Use grouped distributions to compare metagene windows or biological segments
such as upstream, body, and downstream.

Chromosome methylation map
--------------------------

Use this plot for chromosome-scale methylation patterns and broad genomic
structure rather than gene-level interpretation.

Gene PCA
--------

Use PCA to inspect cluster separation, outliers, and the global geometry of the
gene profile matrix.

Gene dendrogram
---------------

Use the dendrogram for hierarchical structure when the retained gene set is
small enough for hierarchical clustering to be practical.

Cluster metagene
----------------

Use this plot after clustering to compare the average methylation profile of
each cluster directly.
