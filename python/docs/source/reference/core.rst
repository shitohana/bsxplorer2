Core API
========

The top-level ``bsx2`` package exposes the core I/O and shared public types used
by both plotting and clustering workflows.

Recommended entrypoints:

- ``RegionReader`` for BSX report access
- ``HcAnnotStore`` for annotation loading
- ``Context`` for methylation context filtering
